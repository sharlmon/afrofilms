# Afrofilms International 🎬

The official digital portfolio and website for **Afrofilms International**, a film production company and collective based in Nairobi and Kilifi, Kenya.

🌐 **Live Website:** [afrofilmsinternational.com](https://afrofilmsinternational.com)

## 📖 About the Project

This platform was designed to encapsulate the cinematic, storytelling-driven nature of Afrofilms. It features sections for their portfolio, team members, galleries, and collective initiatives, providing a seamless and visually engaging experience for potential clients and collaborators.

**Developer's Note:** 
Taking on this project was a significant milestone in my frontend engineering journey. It served as a dynamic, hands-on environment for learning and applying core UI/UX principles from the ground up. Through continuous iteration, problem-solving, and client collaboration, the final product successfully bridged the gap between foundational coding and professional-grade web design.

## 💻 Tech Stack

Based on the repository architecture:
* **Frontend:** JavaScript (98%), HTML5, CSS3
* **Scripting/Utilities:** Python (`extract.py` for data handling)
* **Package Management:** npm
* **Hosting & CI/CD:** Managed Virtual Private Server (VPS)
